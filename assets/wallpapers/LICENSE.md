# Wallpapers

The wallpapers in this directory are free and open-source artwork, included so a fresh
Sleek Shell install looks like the reference desktop without downloading anything.

| Files | Author | License |
|---|---|---|
| `astronaut-planet.jpg` | mvjishnu | GPL-3.0, same as the project ([LICENSE](../../LICENSE)) |
| All other images | their original authors | free / open-source (see the source listed below) |

`astronaut-planet.jpg` was created by mvjishnu with an AI image generator (OpenAI gpt-image).
The embedded provenance metadata was removed for size; this note replaces it.

To keep the repository and the first install small, every wallpaper is fitted to at most
2560x1440, recompressed and stripped of EXIF/XMP metadata. The originals stay untouched in
your own `~/Pictures/Wallpapers` if you already had them.

The remaining wallpapers were collected from free and open-source wallpaper sources and are
redistributed here under their original free licenses. If you are the author of an image and
would like it credited differently or removed, open an issue and it will be handled promptly.

The installer copies this whole directory to `~/Pictures/Wallpapers` and never deletes
wallpapers you added yourself.
